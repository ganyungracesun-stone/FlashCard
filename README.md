# Flashcard Game

A simple interactive flashcard game built with Python, gradio.

The program displays questions as flashcards and allows the user to indicate whether they know the answer. The game keeps track of the user's progress and score.

## Features
Interactive flashcard interface
Displays flashcard questions and answers
Know button
Tracks the user's score
Keeps track of cards that have already been answered

Installation
1. Clone the repository
git clone https://github.com/ganyungracesun-stone/FlashCard.git

Then open the project in PyCharm.

2. Create a virtual environment

In PyCharm, create a Python virtual environment for the project.

3. Install the required packages

Open the PyCharm Terminal and run:

pip install -r requirements.txt
Running the Game

Run the main Python file:

python main.py

Or open main.py in PyCharm and click the Run ▶ button.

How to Play
Start the program.
Read the question displayed on the flashcard.
Click Know if you know the answer.
Click Don't Know if you do not know the answer.
Continue through the flashcards.
Your score is updated as you progress.
